## Class diagrams

This directory contains a few class diagrams for the TSDuck source code.

Files `.drawio` are XML files which are used by the draw.io edition tool.
It is free and open-source. Editing can be performed online or using the
local application.

- Home page: https://www.drawio.com
- Online edition: https://draw.io

The Makefile rebuilds the PNG and PDF versions of the diagrams.

The PNG and PDF files are generated by the makefile, using draw.io in
command line mode. The PNG files which are generated by draw.io are not
optimized. They are too large. The tool `optipng` is used as postprocessing
to compress them.

### Installation on macOS

~~~
brew install --cask drawio
brew install optipng
~~~

### Installation on Ubuntu

~~~
sudo apt install -y snapd ttf-mscorefonts-installer optipng
sudo snap install drawio
~~~

If `.drawio` files are not correctly opened with the draw.io application,
use the following commands to define the assocation.

~~~
xdg-mime default drawio_drawio.desktop application/vnd.jgraph.mxfile
mkdir -p $HOME/.local/share/mime/packages

cat <<EOF >$HOME/.local/share/mime/packages/drawio.xml
<?xml version="1.0" encoding="UTF-8"?>
<mime-info xmlns="http://www.freedesktop.org/standards/shared-mime-info">
  <mime-type type="application/vnd.jgraph.mxfile">
    <comment>draw.io diagram</comment>
    <glob pattern="*.drawio"/>
    <sub-class-of type="application/xml"/>
  </mime-type>
</mime-info>
EOF

update-mime-database $HOME/.local/share/mime
~~~
