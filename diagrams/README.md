## Class diagrams

This directory contains a few class diagrams for the TSDuck source code.

Files `.drawio` are XML files which are used by the draw.io edition tool.
It is free and open-source. Editing can be performed online or using the
local application.

- Home page: https://www.drawio.com
- Online edition: https://draw.io
- Installing draw.io on macOS: `brew install --cask drawio`
