## Class diagrams

This directory contains a few class diagrams for the TSDuck source code.

Files `.drawio` are XML files which are used by the draw.io edition tool.
It is free and open-source. Editing can be performed online or using the
local application.

- Home page: https://www.drawio.com
- Online edition: https://draw.io
- Installing draw.io on macOS: `brew install --cask drawio`

The Makefile rebuilds the PNG and PDF versions of the diagrams.

The PNG and PDF files are generated by the makefile, using draw.io in
command line mode. The PNG files which are generated by draw.io are not
optimized. They are too large. The tool `optipng` is used as postprocessing
to compress them.

- Installing optipng on macOS: `brew install optipng`
